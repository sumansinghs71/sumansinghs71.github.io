Agent Fundamentals

Day 03 — How Production Agents Talk to Systems

Production agents rarely work alone. They call APIs, databases, queues, files, browsers and event systems. The transport should match the job, not the hype.

Simple example

Use REST to fetch an account, a queue for a slow reconciliation job, and a webhook to tell the agent when that job finishes.

Trade-offs

  • Synchronous APIs are simple but can block long work.
  • Events decouple systems but make ordering and debugging harder.
  • Giving the model raw access to every protocol increases complexity.

Production readiness checks

  • Wrap external systems behind stable tool contracts.
  • Add timeouts, retries and idempotency where needed.
  • Record request IDs across system boundaries.
  • Separate read tools from write tools.
