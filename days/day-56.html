Evals and Quality

Day 56 — Tool-Call Evals

Tool-call evals check whether the agent chose the right tool and arguments—not only whether the final sentence sounded good.

Simple example

The answer looks correct, but the agent queried the wrong customer ID; the tool-call eval catches it.

Trade-offs

  • Precise tool evals are easy when there is one correct action.
  • Some tasks allow several valid paths.
  • Tool correctness does not guarantee whole-task success.

Production readiness checks

  • Validate tool name and arguments.
  • Include no-tool-needed cases.
  • Check unauthorized tool attempts.
  • Evaluate sequences, not only single calls.
