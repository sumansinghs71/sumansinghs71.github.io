Safety and Security

Day 21 — Kill Switches

A kill switch is an independent way to stop agents or a class of actions quickly. It should not depend on the same agent runtime that is misbehaving.

Simple example

Security disables all external-send tools across the agent fleet while an incident is investigated.

Trade-offs

  • Broad kill switches protect fast but interrupt healthy work.
  • Very narrow switches may be too slow during incidents.
  • Manual switches require clear ownership.

Production readiness checks

  • Provide global and scoped disable controls.
  • Test them during game days.
  • Make status visible to operators.
  • Define who can activate and restore service.
