Safety and Security

Day 17 — Output Handling

Model output is untrusted input to the rest of your system. Validate it before rendering, executing, storing or sending it elsewhere.

Simple example

An agent returns HTML for a customer portal; the application sanitizes it before display instead of rendering raw model output.

Trade-offs

  • Strict validation can reject useful but slightly malformed output.
  • Repair loops add latency.
  • Free-form text is harder to safely automate than structured output.

Production readiness checks

  • Use schemas for machine-consumed output.
  • Sanitize content before UI rendering.
  • Validate URLs, commands and identifiers.
  • Never execute raw model text directly.
