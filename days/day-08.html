Day 08 — Agent Memory

Agent memory is information intentionally carried across turns or tasks. It should be selected, scoped and removable—not an endless transcript.

Simple example

A service agent remembers the customer prefers email, but does not keep every sentence from every past chat.

Trade-offs

  • More memory can improve continuity but also inject stale facts.
  • Persistent memory creates privacy and deletion obligations.
  • Retrieving too much memory can pollute context.

Production readiness checks

  • Define memory types and owners.
  • Use TTLs or deletion rules.
  • Store provenance and timestamps.
  • Test conflicts between old and new memories.
