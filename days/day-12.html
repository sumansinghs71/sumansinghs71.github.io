Day 12 — Human-in-the-Loop Agents

Human-in-the-loop means a person is part of the control path when judgment, authority or accountability is required.

Simple example

An agent prepares a wire-transfer instruction, but a human approves before money moves.

Trade-offs

  • Review improves control but adds latency.
  • Too many approvals cause rubber-stamping.
  • Humans need enough context to make a real decision.

Production readiness checks

  • Define exactly which actions require review.
  • Show evidence, not only the model's recommendation.
  • Support reject, edit and escalate paths.
  • Track reviewer disagreement and delay.
