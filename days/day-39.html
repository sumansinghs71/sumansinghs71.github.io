Day 39 — File, SFTP, and EDI Integrations

Files, SFTP and EDI still power critical enterprise workflows. Agents must treat them as asynchronous integration surfaces with naming, schema and reconciliation rules.

Simple example

A payments agent watches an SFTP drop, validates a file, sends an acknowledgement, and reconciles the response file later.

Trade-offs

  • Reliable for batch exchange but slow compared with APIs.
  • Partial files and duplicate drops are common edge cases.
  • Schemas may be old and poorly documented.

Production readiness checks

  • Use atomic file arrival patterns.
  • Validate checksums and schemas.
  • Track file IDs end-to-end.
  • Reconcile expected vs received records.
