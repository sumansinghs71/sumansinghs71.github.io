Day 54 — Golden Datasets

A golden dataset is a trusted collection of examples that represent behavior you care about preserving. It should grow from real failures, not only synthetic happy paths.

Simple example

A production incident where the agent refunded the wrong order becomes a permanent regression case.

Trade-offs

  • Curated sets provide stability but require maintenance.
  • Too-clean data can miss messy production behavior.
  • Large sets increase evaluation cost.

Production readiness checks

  • Store provenance for each case.
  • Include hard negatives and failures.
  • Review and retire stale cases.
  • Keep train/tuning data separate from final evaluation where possible.
