Day 55 — LLM-as-Judge

LLM-as-Judge uses a model to score model or agent outputs. It is useful at scale, but the judge is a measurement instrument that must itself be evaluated.

Simple example

A judge scores whether an answer is grounded, while a human calibration set checks whether those scores agree with expert review.

Trade-offs

  • Scales cheaply compared with humans.
  • Judges can prefer style over correctness.
  • Model/provider changes can move the metric.

Production readiness checks

  • Calibrate against human-labeled cases.
  • Version judge prompts and models.
  • Use deterministic checks where possible.
  • Audit disagreements and edge cases.
