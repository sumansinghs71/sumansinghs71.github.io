Day 61 — CodeAct / Code-as-Action Agents

Code-as-Action lets an agent write and run small programs to perform deterministic transformations instead of bouncing through many model/tool calls.

Simple example

The agent writes a script to load 20 CSV files, filter rows, compute totals and create one result rather than reasoning over every row in context.

Trade-offs

  • Code can reduce tokens and improve determinism.
  • Generated code expands the execution attack surface.
  • Debugging needs access to code, stdout and artifacts.

Production readiness checks

  • Run code in an isolated sandbox.
  • Restrict network, filesystem and packages.
  • Set CPU, memory and time limits.
  • Persist code and outputs for audit/replay.
