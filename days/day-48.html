Day 48 — Scheduling Agents

Scheduling runs agent work at a future time or on a recurring cadence. Time becomes part of correctness.

Simple example

An agent checks certificate expiry every morning and only creates work when a threshold is crossed.

Trade-offs

  • Schedulers are simple until time zones, DST and retries appear.
  • Recurring jobs can overlap if a run is slow.
  • Missed schedules need catch-up rules.

Production readiness checks

  • Store schedules in a clear time zone.
  • Prevent or explicitly allow overlapping runs.
  • Define missed-run behavior.
  • Audit schedule changes.
