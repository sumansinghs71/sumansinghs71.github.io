Safety and Security

Day 15 — Data Access Boundaries

Data boundaries define which tenant, user, region or classification an agent can see. Retrieval must enforce the same boundaries as the source systems.

Simple example

A multi-tenant RAG agent must never retrieve another company's documents even if the vector similarity is high.

Trade-offs

  • Strict filters can reduce recall.
  • Duplicating indexes simplifies isolation but costs more.
  • Post-filtering may leak candidates before policy checks.

Production readiness checks

  • Apply tenant and user filters before returning content.
  • Test cross-tenant queries.
  • Carry authorization metadata into indexes.
  • Log the data scope used for every retrieval.
