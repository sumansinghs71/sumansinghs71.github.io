# Suman Singh — personal research & AI engineering site

Static first version of `sumansinghs71.github.io`.

## Publish on GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the root of `sumansinghs71/sumansinghs71.github.io`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Save and wait for GitHub Pages to publish.

The site will appear at `https://sumansinghs71.github.io/`.
