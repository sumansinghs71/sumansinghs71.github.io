what actually broke.

Production-shaped failure patterns around AI systems: model gateways, runtimes, code sandboxes, identity, RAG, tools and conventional dependencies. Each page names the failure boundary and gives concrete prevention, detection, recovery and failure-injection measures.

Public-safe by design: examples are intentionally generalized. The point is the engineering pattern, not any organization, provider incident or internal implementation detail.
